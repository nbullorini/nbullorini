## What I do

I've been building software for about 17 years. I started as a developer at Argentina's National Congress and later served as Deputy Director of Systems and Electronics. Since 2018 I've run Microblet Labs, where I lead a remote team building custom business software.

My work covers the whole path to production: architecture, backend, frontend, cloud infrastructure, CI/CD and security. Infrastructure and security have always been a big part of it, not an afterthought.

Microblet works as an AI-driven software factory. Senior engineers set the architecture and quality bar, AI agents do much of the implementation in parallel, and every change goes through human review before it ships. Day to day that means Claude Code, agent orchestrators, MCP and parallel agents on git worktrees.

I'm also the creator and maintainer of **[laranest.dev](https://laranest.dev)** ([GitHub](https://github.com/nbullorini/laranest)), which runs your existing Laravel projects locally with zero configuration: their own PHP, workers and HTTPS per app, with no sudo or Docker, on Linux, WSL2 or Windows.
